1. Programming the Dongle
11 Steps ▼
1 Connect maintenance dongle to the FLMD using the Dongle Adapter
2 Delete all files inside the maintenance dongle, ensure Dongle is empty before programming
3 Copy the entire PMI folder of the target Zone to desktop and unzip
4 Double-click on the autorun.exe file
5 Click on "ProDongle" button and click on "Program"
6 Choose the drive letter where Maintenance Dongle is connected
7 In the MGM/SCOM Key Programming window, select the target SCOM (SCOM_A or SCOM_B) from the dropdown list. Then click on "Program" button to start the dongle programming process
8 Click "OK" when pop-up window stating "Key programming succeeded" to close the window
9 Go inside the Dongle and check that a CIL.bin file has been created
10 Copy and paste the following folders into the dongle:
📁 Step1 - SCOM Retrofit
📁 CONF_PMI_SGPR_ZC01_005-01

3. Install Revenue Software
20 Steps ▼
1 Install SCOM Revenue SW (available on desktop) which will update the IP addresses of these network ports
2 Double-click on the autorun.exe file inside the PMI folder on the Desktop. An AutorunPMI window will pop-up
3 Select "ProDongle"
4 Check which drive the dongle is saved in (e.g, :C/, :D/, :E/)
5 Select that drive in the box. Click on "MGM/SCOM"
6 Select the desired zone and SCOM (A/B) and click on "Program"
7 Once done, click on "Return" until returned to the starting page
8 Select either SCOM A or SCOM B and ensure the right zone is selected
9 If prompted with a similar prompt as in Figure 21 below, select "OK"
10 A black command window will appear indicating start of SCOM programming
11 If a pop-up appears, click "ignore". Repeat for every pop-up that appears
12 A green command window will appear (about 1 – 2 seconds only) indicating SCOM has been programmed
13 Upon successful installation, click the "Quit" button and SCOM UT will auto restart. If it does not auto-restart, attempt the dongle and SCOM programming again
14 Upon start-up of SCOM, do not close all MS-DOS windows that appear. It will show the wallpaper of the corresponding SCOM
15 Go to D:/SCOM (SCOM folder present in the D drive). Double click on the OutputSignature.txt text file. Check the first line of the text file as shown CRC
16 Check with EMM/FE to verify the CRC number that should be shown here
17 Double-click Network Connection icon on desktop. Right-click on LAN 2 – InterSCOM 2 and select Properties. Click on "Internet Protocol Version 4 (TCP/IPv4)" > Properties. Check that "LAN 2 – InterSCOM 2" IP address and subnet mask is as follow:
For SCOM A: IP Address = 10.10.18.2 | Subnet mask = 255.255.255.0
For SCOM B: IP Address = 10.10.18.3 | Subnet mask = 255.255.255.0
18 Verify and set the network adapter speed port properties for LAN5 – DCS connection as followed:
Right-click on "LAN 5 – DCS connection" and select "Properties". Click on "Configure"
Click on the "Advanced" tab:
Duplex – Full-Duplex
Receive Buffers – 16 (Default value)
Speed – 10Mbps at stations (Take note that it is 100 Mbps for TWD)
Transmit Control Block – 8 (Default value)
19 Set Disabled for all unused ports (LAN 2 - Not Used, LAN 6, LAN 7, LAN 9)
20 Go to "Start" >> "Startup" >> "Start SCOMX v02_32_02_XX". It should only show one SCOM version (latest version)

4. Troubleshooting & Important Notes
4 Topics ▼
🔧
SCOM UT cannot access BIOS

Switch OFF UT by pushing the front power button for 5 seconds then switch ON UT again by pushing front power button for 5 seconds. While UT is rebooting, immediately press on DEL key to access UT BIOS. If failed, repeat this process again.

🚨
SCOM UT boots-up in Windows and indicating dongle failed or error

Modify CD drive to F: drive (Go to "Start" menu. Click on "Run" then type in diskmgmt.msc and press "OK" to open the Disk Management window to modify it). Once done, check that dongle is correctly seen on E: drive (Shortcut key: "Windows + R" key to open the run dialog).

⚡
SCOM UT does not switch on

Perform the following steps and move on to the next step if the problem is not resolved:

Check UT rear power button is switched on
Check UT power cord
Check power point is switched on
If issue persist, replace UT
🔐 Verify MD5 checksum of Software Files
Press 'Windows' + 'R' to open Windows command line. Type cmd and press Enter.
Type cd X: where X is the path that contains the latest software CD, and press Enter. (Eg: Type cd E: to access the path that contains latest software CD)
Type certutil -hashfile YYY MD5 where YYY is the path to the file, and press Enter. (Eg: Type certutil -hashfile bootmgr MD5 to get the MD5 hash for the corresponding file.) Compare certutil -hashfile bootmgr MD5
