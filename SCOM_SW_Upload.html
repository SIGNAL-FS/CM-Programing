🌐 2. SCOM LAN Setup
7 Steps ▼
1Go to D:\SCOM\unist000.exe and double-click to remove previous config files. Select "Yes".
2Double-click Network Connections on Desktop. Go to View > Details > Status to list LAN ports.
3Check disabled LAN ports:
LAN 2 – Not Used – Disabled
LAN 6, 7, 9 – Disabled
4Other ports should show "Network cable unplugged":
LAN2 – InterSCOM 2 (Intel 82574L)
LAN2 – Not Used (Intel 8255xER #5)
LAN3 - NETP, LAN4 - LogFiles, LAN5 - DCS, LAN8 - InterSCOM
⚠️ Save image as network_connections.png
Fig: Verify LAN 2 – Not Used (Disabled) & LAN 2 – InterSCOM 2 (Unplugged)
5[If needed] If LAN2-InterSCOM 2 missing Intel 82574L:
Run Autorun.exe in Step1 – SCOM Retrofit folder
If missing, run Intel PROSet 14-6.exe from CPU board driver folder
Run Autorun.exe in LAN folder
Run Driver installation – recover advanced tab.bat
6Rename ports:
"LAN 2 – InterSCOM2" ➔ "LAN 2 – Not Used"
"LAN 1" ➔ "LAN 2 – InterSCOM 2"
7Set Disable/Enable and refresh:
"LAN 2 – Not Used" Disable
"LAN 2 – InterSCOM 2" ➔ Enable
3. Install Revenue SW
20 Steps ▼
1Install SCOM Revenue SW (on desktop) to update IP addresses.
2Double-click autorun.exe in PMI folder on Desktop.
3Select "ProDongle".
4Check dongle drive letter (e.g., C:, D:, E:).
5Select drive and click "MGM/SCOM".
6Select desired zone and SCOM (A/B), click "Program".
7Click "Return" until back to starting page.
8Select SCOM A or B, ensure right zone is selected.
9If prompted (Fig 21), select "OK".
10Black command window appears (start of programming).
11If pop-up appears, click "ignore". Repeat for all.
12Green command window appears (1-2 secs) = programmed.
13Click "Quit". SCOM UT will auto-restart. If not, retry programming.
14Do NOT close MS-DOS windows on start-up. Wallpaper will show.
15Go to D:/SCOM, open OutputSignature.txt. Check first line CRC.
16Verify CRC number with EMM/FE.
17Check LAN 2 – InterSCOM 2 IPv4 Properties:
SCOM A: 10.10.18.2 / 255.255.255.0
SCOM B: 10.10.18.3 / 255.255.255.0
18Verify LAN5 – DCS Advanced properties:
Duplex: Full-Duplex
Receive Buffers: 16
Speed: 10Mbps (100Mbps for TWD)
Transmit Control Block: 8
19Disable all unused ports (LAN 2-Not Used, 6, 7, 9).
20Start >> Startup >> "Start SCOMX v02_32_02_XX". Ensure only latest version shows.
⚠️ 4. Troubleshooting
Notes ▼
🔧 Cannot access BIOS

Switch OFF UT (hold power 5s), switch ON. Immediately press DEL repeatedly while rebooting.

🚨 Dongle failed/error on boot

Modify CD drive to F: via diskmgmt.msc. Ensure dongle is seen on E:.

⚡ UT does not switch on

1) Check rear power button. 2) Check power cord. 3) Check power point. 4) Replace UT if persists.

🔐 Verify MD5 Checksum
Press Win+R, type cmd, press Enter.
Type cd X: (e.g., cd E:) to access software CD path.
Type certutil -hashfile bootmgr MD5 and compare hash.
